# Enterprise CRM

A CRM I built to see how far I could get without a backend.

Live: https://bxzex.github.io/enterprise-crm/

There's a dashboard with revenue and conversion charts, a client list you can add to and edit, a sales pipeline with deal stages and values, and a task list sorted by urgency. Everything is saved in your browser's localStorage, so there's no server and no login.

React, TypeScript, Tailwind v4, Recharts and Framer Motion. `npm install` then `npm run dev` to run it, `npm run deploy` to publish to Pages.
